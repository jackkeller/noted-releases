# Noted releases

Downloads and the update feed for [Noted](https://jackkeller.dev/apps), a native
macOS markdown writing app with Claude Code built in.

- **Latest version:** [Noted.dmg](https://github.com/jackkeller/noted-releases/releases/latest/download/Noted.dmg)
- **All versions:** see [Releases](https://github.com/jackkeller/noted-releases/releases)
- **Bugs and ideas:** [open an issue](https://github.com/jackkeller/noted-releases/issues/new/choose)
- **What's coming:** the [roadmap](ROADMAP.md)
- `appcast.xml` is the [Sparkle](https://sparkle-project.org) feed the app checks
  for updates. Each release attaches the DMG twice: versioned (the appcast points
  there) and as plain `Noted.dmg`, which always serves the newest version.

The source repository is private; this repo only hosts release artifacts.
